# Paper build

`main.tex` is the single source. It builds as an IEEE conference paper (ICRA)
by default and is written so the ICLR switch is a preamble change, not a
rewrite.

## Build (ICRA / IEEE)

```
cd paper
pdflatex main && pdflatex main
```

Needs `IEEEtran.cls`, which ships with TeX Live and MiKTeX. No bibliography
tool is required: references are a `thebibliography` block, so two passes are
enough.

## ICRA compliance

| requirement | status |
|---|---|
| IEEEtran, `conference` option | yes |
| two column, 10 pt, US letter | from the class |
| 8 pages including references | **check before submitting** — see below |
| anonymous | **no** — ICRA is single-blind, author block is filled in |

ICRA allows 8 pages including references, with extra pages at a charge. Run
`pdflatex` and check the page count; if it runs over, the first things to cut
are §II (related work, compressible to one paragraph) and the post-hoc
subsection in §VI.

## Switching to ICLR

ICLR is single column, 9 pages excluding references, and **double blind**.
Three changes:

1. **Preamble.** Replace the `\documentclass` and author block with
   `iclr2027_conference.sty` from the official template, and use
   `\usepackage{iclr2027_conference}` for the anonymous build.
2. **Anonymise.** Remove the author block and — importantly — the repository
   URL, which identifies the author. `\repo` is defined once at the top of
   `main.tex` precisely so it can be redirected to an anonymised mirror in one
   edit.
3. **Figures.** `\columnwidth` becomes `\textwidth` for single column. The
   figure is a raster PNG at 200 dpi and will hold up at the larger size.

The body deliberately contains no two-column-specific markup (no `figure*`, no
`\raggedbottom` tricks, no column-balancing), so the switch is mechanical.

## What is deliberately not in the paper

- **No hardware results.** The robot is not built. §Limitations says so
  plainly; do not let a later draft soften that.
- **No claim that the interface hypothesis holds.** It was pre-registered and
  it failed at the pre-registered operating point. The post-hoc observation in
  §VI is labelled as such and must stay labelled.

## Figures

`figures/h4_interface_anisotropy.png` is regenerated by
`run.cmd tools/h4_figure.py` from `results/h4_sweep_{velocity,force}.json`.

`tools/h4_landscape.py` produces the 2-D transfer landscape from
`results/h4_grid_{velocity,force}.json`; it is not yet referenced by the paper
because those sweeps were still running when this draft was written.
